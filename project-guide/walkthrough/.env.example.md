# .env.example (repo root)

## 1. Purpose
A template for environment variables at the repo root. The file has only one comment line saying "do not place secrets here". The real per-app templates live in `passenger-app/`, `driver-app/` and `backend/` (see `README.md:36-42`).

## 2. Imports, one by one
None. It is a plain text file.

## 3. Walk through the code
`# Root environment-variable template; do not place secrets here.` (`.env.example:1`). A line starting with `#` is a comment, and tools ignore it. No variable is defined. **Environment variable** (a named setting kept outside the code. *Example:* `API_BASE_URL=http://10.0.2.2:8000`).

## 4. How data flows
None. No program reads this file. Nothing flows.

## 5. Try it
`cat .env.example` shows the single comment line.

## 6. Can it be better?
- Good: warns against secrets.
- Weak: it is empty, so it may confuse readers. Either remove it or list shared keys.
- Security: keep real `.env` files out of git (README says they are excluded, `README.md:69`).
