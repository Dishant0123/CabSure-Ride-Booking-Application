# passenger-app/ios/.xcode.env

## 1. Purpose
This tiny file tells Xcode (Apple's app-building tool) where the `node` program is. Xcode runs script steps while it builds the iOS app. Those steps need Node to bundle the JavaScript code. The file sits in the iOS folder and is read by React Native's build scripts, not by your own code.

## 2. Imports, one by one
There are no imports. The file only sets one shell variable. (**Shell variable**: a named value in a terminal script. *Example:* `NAME=rem` then `echo $NAME` prints `rem`.)

## 3. Walk through the code, top to bottom
- Lines 1-4 (`passenger-app/ios/.xcode.env:1-4`) are comments. A line that starts with `#` is ignored. They say the file is saved in git, and that you can make a private `.xcode.env.local` file that git does not track.
- Lines 6-10 are comments about `NODE_BINARY` (the full path to the node program). Line 10 shows how to use `nvm` (a Node version manager) with Homebrew on a Mac.
- Line 11: `export NODE_BINARY=$(command -v node)`
  - `export` makes the variable visible to programs started later (like the Xcode build scripts).
  - `$(...)` runs the command inside and pastes its output. This is called command substitution.
  - `command -v node` prints the path of the first `node` found in your PATH. *Example output:* `/usr/local/bin/node`.
  - So `NODE_BINARY` becomes that path.
  - If node is not in PATH, the value is empty and the iOS build fails.

## 4. How data flows
```
Xcode build -> reads .xcode.env -> runs `command -v node`
            -> NODE_BINARY=/path/to/node -> RN bundle script uses it
```

## 5. Try it
Not directly runnable by itself. You can see its idea in zsh:
```sh
export NODE_BINARY=$(command -v node); echo "$NODE_BINARY"
```
Expected: a path such as `/home/rem/.local/share/mise/installs/node/26/bin/node`. Note: iOS builds need macOS, so on your Arch machine this file is not used.

## 6. Can it be better?
- Good: it is short, standard, and works for most setups.
- Weak: if Xcode starts with a different PATH than your terminal (common with mise/nvm), node may not be found. Then set the path by hand in `.xcode.env.local`.
- Cleaner way (opinion): keep the default and put a fixed path in `.xcode.env.local` only if the build fails.
- Security: no secrets here.
