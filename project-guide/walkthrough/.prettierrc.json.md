# .prettierrc.json (repo root)

## 1. Purpose
Settings for **Prettier** (a tool that re-formats code so the whole team uses one style. *Example:* it turns `a=1` into `a = 1;`). Running Prettier in this repo reads this file. It affects the JS/TS apps.

## 2. Imports, one by one
None. It is JSON.

## 3. Walk through the code
The object has five keys (`.prettierrc.json:1-7`):
- `"singleQuote": true`: use `'text'`, not `"text"`.
- `"trailingComma": "all"`: put a comma after the last item in lists, objects and function calls, so adding an item changes only one line in git.
- `"tabWidth": 2`: indent by two spaces.
- `"semi": true`: end statements with `;`.
- `"printWidth": 100`: wrap lines longer than 100 characters.

## 4. How data flows
```
editor/CLI -> Prettier reads .prettierrc.json -> rewrites the source file
```

## 5. Try it
`pnpm dlx prettier --check "driver-app/src/**/*.ts"` (`dlx` runs a tool without installing it; `--check` only reports files that differ; quoted glob for zsh). Expect a list of files that need changes. Add `--write` to fix them. Note: `DriverNavigator.tsx` has lines over 100 characters, so it would be rewritten.
